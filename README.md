# Descripción del Trabajo Practico
La propuesta elegida es la de Agencia de Turismo "Rumbo Sur" que organiza tours y 
excursiones  con salidas programadas. El sistema debe ordenar el catálogo, las salidas,
las reservas, los pasajeros, las tarifas, los pagos, los servicios adicionales, 
las cancelaciones, la asignación de guía y transporte, las liquidaciones y los reportes.

El objetivo del trabajo practico es diseñar un sistema orientado a objetos que permita
administrar la oferta turística, vender reservas y organizar la operación de cada salida
respetando las reglas de negocio.
